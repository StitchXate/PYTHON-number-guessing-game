# PYTHON-number-guessing-game
 Python project: a simple Number Guessing Game built to practice loops, conditionals, random numbers, and user input.

## Features
- Random number generation
- Too High / Too Low hints
- Counts the number of attempts
- Displays a winning message


## What I Learned
- Variables
- User input
- Loops
- Conditional statements
- Random module

## Future Improvements
- Difficulty levels
- Maximum number of attempts
- Play Again option
- Input validation
